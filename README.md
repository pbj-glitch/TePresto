## 📌 2. Visión del Proyecto

### ❓ Problema
Los vecinos de una comunidad (edificios, condominios, barrios) no cuentan con una herramienta eficiente, segura y organizada para prestar o arrendar objetos de uso ocasional entre ellos.

### 🎯 Usuario Objetivo
Personas mayores de 18 años que forman parte de comunidades establecidas (edificios, condominios, barrios, pasajes) y buscan optimizar el uso de recursos compartidos.

### 💡 Propuesta de Valor
> *Ahorra en la compra de objetos para uso único y optimiza de forma segura el proceso de préstamo en tu comunidad.*

---

## 🚀 3. Funcionalidades Principales (MVP)

1. **Feed Interactivo:** Listado de objetos publicados para arriendo o préstamo en la comunidad.
2. **Solicitud de Arriendo/Préstamo:** Sistema de notificaciones para solicitar y gestionar necesidades específicas.
3. **Chat Privado:** Mensajería directa entre el prestador y el solicitante para coordinar detalles y entregas.
4. **Sistema de Calificación:** Evaluación mutua del servicio para construir reputación y confianza.
5. **Historial y Garantía:** Registro histórico de transacciones junto con un sistema de garantía para protección de los objetos.

---

## 🛠️ 4. Stack Tecnológico y Dependencias

- **Frontend:** Ionic + Angular
- **Backend & Base de Datos:** Django y PostgreSQL
- **Almacenamiento de Imágenes:** Cloudinary / AWS S3
- **Chat en Tiempo Real:** Firebase Realtime Database / Stream Chat
- **Notificaciones Push:** Firebase Cloud Messaging (FCM)
- **Pasarela de Pagos:** MercadoPago / Transbank Webpay
- **Mapas y Geolocalización:** API Google Maps
- **Seguridad & Identidad:** API de validación de identidad (Escaneo de carnet)
